# 지하철 러쉬 (Subway Rush)

버스에서 내린 뒤 **180초 안에 지하철에 탑승**해야 하는 시간제한 어드벤처 퍼즐.

속도가 아니라 **정보 부족**이 플레이어를 막는다. 어느 개찰구가 살아있는지, 어느 에스컬레이터가 뚫려있는지, 저 할아버지에게 말을 걸 가치가 있는지 — 모르면 시간이 녹는다. 그래서 첫 플레이는 반드시 실패하며, 그 실패조차 엔딩으로 처리한다.

**[캐릭터 페이지 →](https://sunes26.github.io/subway-rush/)** — 4면도와 애니메이션을 브라우저에서 재생해볼 수 있다.

## 캐릭터

전부 흰색 무표정 블롭을 베이스로 하고, **액세서리로만 변주**한다. 색 없이 실루엣만으로 구별되는 것이 조건이다.

| ID | 이름 | 높이 | 본 | 애니메이션 |
|---|---|---|---|---|
| ACT-01 | 플레이어 | 0.923 | 17 | 9종 |
| ACT-02 | 할아버지 | 0.836 | 19 | 6종 |

두 리그는 **본 이름과 회전 부호 규약이 동일**하다. 애니메이션 리타게팅이 가능하다.

```
Spine / Chest / Hips / Head   rx +  = 앞으로 숙임
UpperLeg                      rx −  = 앞으로
UpperArm                      rx +  = 뒤로
```

## 엔진 연동 시 주의

- **`export_apply`는 반드시 `False`.** `True`면 Armature 모디파이어까지 적용돼 리깅이 사라진다.
- **애니메이션 익스포트는 NLA 트랙 모드.** 두 리그의 본 이름이 같아서 `ACTIONS` 모드로 내보내면 상대 캐릭터의 액션까지 섞여 들어간다.
- **루트 모션 없음.** 제자리 애니메이션이므로 이동은 코드로 처리한다.
- **발도 연출** — `GP_Draw` 14프레임에서 오른손이 가슴에 닿는다. 그 시점에 단소의 부모를 `Prop.Chest` → `Prop.R`로 교체한다. glTF가 런타임 리페어런팅을 표현하지 못해 엔진 쪽에 남긴 부분이다.

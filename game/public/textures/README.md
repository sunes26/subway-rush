# 엔딩 창밖 배경

여기에 파일을 놓으면 엔딩 컷의 창밖이 **자동으로 그 그림으로 바뀐다.**
없으면 `src/render/ending-stage.ts` 가 캔버스로 그린 폴백이 그대로 쓰인다 —
파일이 없는 상태도 정상이고, 게임은 깨지지 않는다.

| 파일명 | 쓰이는 곳 |
|---|---|
| `ending-dawn.webp` | SUCCESS · JUST IN TIME — 한강 일출 |
| `ending-hell.webp` | WRONG WAY — 지옥 |

## 규격 — **거의 아무 가로 이미지나 된다**

창은 12m × 1.6m, 즉 **7.5:1** 이다. 그런데 그 비율로 그림을 만들어 올 필요는 없다:
로드할 때 원본에서 **가로 띠를 잘라** 비율을 맞추므로(`ending-stage.ts loadOrDraw`)
16:9 든 3:1 이든 늘어나지 않는다. 잘리는 띠는 위에서 30% 지점 근처다.

- **가로 해상도가 전부다.** 화면에 들어오는 창 폭이 약 5.7m 이고 그것이 원본의
  절반쯤을 차지하므로, 가로 2048px 이면 화면에서 거의 원본 크기로 보인다.
  2048~3072px 를 권장한다. 세로는 잘려 나가므로 넉넉해도 손해가 아니다.
- **좌우 끝은 안 맞아도 된다.** 반복을 껐다(`repeat 1`) — 한 장이 창 전체를 덮고,
  컷 동안 흐르는 거리가 한 장의 7~9% 라 이음매가 화면에 안 들어온다.
- 지평선(강물 경계 · 용암 경계)이 **위에서 30~45%** 사이에 있으면 잘리는 띠에 들어온다.
  하늘만 있거나 물만 있는 구도는 피할 것.
- WebP 품질 80 기준 한 장 100~200KB.

## 그림 안에 넣지 말 것

- **글자.** 흐르는 배경이라 읽기 전에 지나간다. 안내 문구가 필요하면 차내 안내판
  (`drawLed`)이나 별도 판으로 띄운다.
- **화면 가장자리에만 있는 랜드마크.** 카메라가 보는 것은 그림의 가운데 절반쯤이다.
  해·지옥문은 **가로 중앙 부근**에 두는 것이 안전하다.

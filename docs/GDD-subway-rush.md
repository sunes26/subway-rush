## 1. 컨셉

### 1.1 한 줄 정의
> **버스에서 내린 순간부터 지하철 문이 닫히기까지 — 180초 안에 대한민국 출근길을 돌파하라.**

### 1.2 디자인 스테이트먼트
이 게임은 "달리기 게임"이 아니라 **"관찰하고 판단하는 게임"**이다.
플레이어를 막는 건 속도가 아니라 **정보 부족**이다. 어느 개찰구가 살아있는지, 어느 에스컬레이터가 뚫려있는지, 저 할아버지에게 말을 걸 가치가 있는지 — 이걸 모르면 시간이 녹는다.

그래서 **첫 플레이는 반드시 실패한다.** 그리고 그 실패조차 엔딩으로 처리한다. 실패가 콘텐츠가 되는 순간 플레이어는 다시 시작한다.

### 1.3 핵심 감정
| 순간 | 의도한 감정 |
|---|---|
| 타이머 60초 남음 | 초조 |
| 개찰구 5개 중 1개 고름 | 도박 |
| 효자손으로 자판기 긁어 동전 나옴 | 쾌감 + 웃음 |
| 문 닫히기 0.4초 전 탑승 | 카타르시스 |
| 놓쳤는데 특이한 엔딩 나옴 | "어? 이것도 있네?" → 재도전 |

### 1.4 레퍼런스 포지셔닝
- 시간 압박 + 다중 엔딩: *Papers, Please* / *Minit*
- 환경 관찰 퍼즐: *Unpacking*, *Please Touch The Artwork*
- 생활 공감 코미디: *Job Simulator*, 한국 웹툰 감성
- **차별점**: "한국인만 아는 지하철 고증"이 곧 게임 메카닉이다. (좌측 통행, 스크린도어, 1회용 교통카드 보증금 500원, 도 아세요 아주머니)

## 2. 핵심 루프

```
   [관찰] ──► [경로/수단 선택] ──► [방해요소 조우]
      ▲                                   │
      │                                   ▼
   [시간 갱신] ◄── [해결 or 우회 or 강행] ◄─┘
      │
      └──► 다음 구역 (Zone) ──► ... ──► 승강장 ──► 엔딩 판정
```

**모든 행동은 초(秒)를 지불한다.** 시간이 이 게임의 유일한 화폐다.

| 행동 | 비용 |
|---|---|
| 걷기 | 기본 |
| 스프린트 | 이동시간 -40%, 스태미너 소모, 인파 충돌 확률 ↑ |
| 아이템 습득 | 0.8초 |
| 아이템 사용 | 1~3초 |
| NPC 대화 | 5~15초 |
| 잘못된 선택 (고장 개찰구 태그) | 8초 + 뒤로 밀림 |
| 넘어짐 | 6초 + 인벤 1칸 드랍 |

## 3. 스테이지 구조 — 5개 존

총 제한시간 **180초** (열차 도착 예정 시각까지). 상단 LED 전광판이 카운트다운.

| Zone | 이름 | 목표 통과 시간 | 핵심 방해요소 |
|---|---|---|---|
| **Z1** | 버스 하차 ~ 지하철 입구 | 20s | 횡단보도 신호, 인도 노점, 전단지 배포원 |
| **Z2** | 대합실 / 통로 | 45s | 자판기, 충전기, 화장실, 유실물, 할아버지 벤치 |
| **Z3** | 개찰구 | 30s | 개찰구 N개 중 1개만 정상 / 잔액부족 |
| **Z4** | 수직 이동 (하강) | 35s | 에스컬레이터 인파, 계단, 물청소 구역 |
| **Z5** | 승강장 | 50s | 하차 인파 역류, 줄서기, 문 위치, 스크린도어 |

> **설계 원칙**: Z2가 "자원 획득 구간", Z3가 "관문 구간", Z5가 "타이밍 구간"이다.
> Z2에서 욕심내면 Z5에서 죽는다. 이 트레이드오프가 게임의 척추.

## 4. 방해요소 (Obstacle) 카탈로그

각 방해요소는 **감지 단서 / 해결 수단 / 실패 비용** 3요소를 반드시 갖는다.
*단서 없는 방해요소는 방해요소가 아니라 랜덤 처형이다.*

| # | 방해요소 | Zone | 감지 단서 | 해결 수단 | 실패 비용 |
|---|---|---|---|---|---|
| O-01 | **고장난 개찰구** | Z3 | 게이트 램프 색(초록/적색), 앞사람 통과 여부, 바닥 마모도 | 관찰 후 정상 게이트 선택 / 할아버지 힌트 / 노선도 | -8s, 뒤로 밀림 |
| O-02 | **교통카드 잔액부족** | Z3 | 게임 시작 시 지갑 UI에 잔액 표시(랜덤 0~2000원) | 동전 수집(자판기·바닥, 습득 즉시 자동 충전) / 충전기 사용(-12s) / 역무실 사정 | -6s + 재시도 |
| O-03 | **에스컬레이터 인파벽** | Z4 | 좌측에 캐리어 든 승객이 서 있음 (좌측통행 위반) | 우산으로 손잡이 걸고 비켜서기 요청 / 계단 우회 / "저기요" 외침(-3s) | 15s 정체 |
| O-04 | **하차 인파 역류** | Z5 | 반대편 열차 도착 안내음 + 화면 가장자리 붉은 경고 | 벽에 붙어 3초 대기 / 마스크 착용 후 강행 | 밀려서 -10s, 넘어질 확률 30% |
| O-05 | **물청소 구역** | Z4 | 노란 삼각 표지판, 바닥 반사광 | 신문지 깔기 / 우회 / 천천히 걷기 | 미끄러짐 -6s + 아이템 드랍 |
| O-06 | **전단지 배포원** | Z1 | 손 뻗은 모션 | 무선이어폰 착용 / 반대편 인도 | 붙잡힘 -5s |
| O-07 | **"도 아세요" 아주머니** | Z2 | **2인 1조.** 눈 마주치면 접근 시작 | 무선이어폰 / 시선 회피(카메라 조작) / 대화 완주(-15s, 대신 정보 획득) | -15s. 둘이 양옆에서 협공하므로 우회로가 좁다 |
| O-08 | **좀비폰족** | Z2/Z4 | 고개 숙이고 지그재그 이동 | 회피 이동 / 캐리어로 방어 | 충돌 -4s |
| O-10 | **공사중 출구 안내** | Z2 | "○○방면 통로 폐쇄" 표지판 | 노선도 아이템으로 대체 경로 확인 | 막다른 길 -20s |
| O-11 | **승차 대기줄 오선택** | Z5 | 줄 길이, 열차 문 정차 위치 마킹(바닥 숫자) | 노선도로 문 위치 예측 / 짧은 줄 | 탑승 실패 |
| O-12 | **스크린도어 닫힘** | Z5 | 3초 경고음 + 점멸 | 스프린트 슬라이딩 | 문틈 낑김 or 탑승 실패 |
| O-13 | **역무원 순찰** | Z3 | 시야 콘 표시 | 정상 통과 / 시야 밖 대기 | 부정승차 적발 시 즉시 배드엔딩 |
| O-14 | 🎋 **할아버지 단소 추격** | Z2→Z3 | 절도 순간 즉시 발동 (경고 없음, 그게 벌이다) | 스프린트로 이탈 / 개찰구 통과 / 효자손 반납 | 피격당 이동속도 -20% (누적 최대 -100%) |

> **랜덤 시드**: 정상 개찰구 번호 · 초기 카드 잔액 · 인파 웨이브 패턴 · 물청소 위치는 매 플레이 시드 기반 재배치. **암기 공략을 막고 관찰을 강제한다.**
> 단, **O-14는 시드 무관 — 플레이어 선택으로만 발동한다.** 이 게임에서 유일하게 "자업자득"인 방해요소.

### 4.1 O-14 상세 — 할아버지 단소 추격 🎋

효자손을 훔치면, 할아버지가 품에서 **단소**를 꺼내 든다.

```
     [효자손 절도 성공]
              │
              ▼
   할아버지 기립 → 단소 발도(拔刀) 연출 0.6s
              │  "이놈이!"
              ▼
   ┌──────────────────────────────────┐
   │  추격 지속 10초 (또는 Z3 진입까지) │
   │  이동속도 = 플레이어 걷기와 동일    │
   │  → 스프린트로만 거리 벌기 가능      │
   └──────────────────────────────────┘
              │
      거리 ≤ 1.2m 진입
              │
              ▼
   단소 스윙 (1.5s 쿨다운) ── 1대째 명중 ──► 이동속도 -20% 누적
              │                              + 화면 흔들림 + "딱!" SFX
              │                              + 양심 -1
              ▼
      2대째 명중
              │
              ▼
   즉시 게임오버 — E-16 "결국 붙잡혔다"
```

**파라미터**

| 항목 | 값 | 근거 |
|---|---|---|
| 추격 지속 | 10s (Z3 진입 시 즉시 해제) | 개찰구가 명확한 "안전지대" 목표를 준다 |
| 할아버지 이동속도 | 플레이어 걷기와 동일 (100%) | 그냥 걸으면 절대 못 벗어남 → **스프린트 강제 = 스태미너 압박** |
| 타격 반경 | 1.2m | 플레이어 상호작용 반경(1.5m)보다 좁게 → 아이템 줍다 맞는 상황 유발 |
| 스윙 쿨다운 | 1.5s | 연타 즉사 방지 — 한 번 맞고도 도망칠 창을 준다 |
| 피격당 감속 | -20% (누적) | 1대는 경고다. 감속으로 끝나는 건 여기까지다 |
| 감속 회복 | +5%/s (비피격 시) | **도망치면 회복된다** → 회복 가능성이 긴장을 유지 |
| 피격당 양심 | -1 (회당) | 절도 -3 + 피격 → E-10 배드엔딩 압박 |
| 즉사 조건 | **2대째 피격** | 예전엔 5대 누적 회수였다. 즉사로 바꾸면서 성격이 달라졌다 — 시간 손해가 아니라 판돈이다 |
| 해제 조건 | Z3 진입 / 10s 경과 / 할아버지에게 효자손 반납 | 반납 시 양심 +1 회복, 효자손은 잃음 |

**왜 이 설계인가**

절도 루트는 원래 "시간을 아끼는 대신 양심을 잃는" 거래였다. 그런데 양심 페널티는 **엔딩 화면에서야 청구서가 온다.** 너무 늦다.

단소 추격은 그 청구서를 **즉시, 몸으로** 보낸다. 첫 대는 경고다 — 감속(`CHASE.hitPenalty`)과 "딱!"으로 손해를 알린다. 두 번째 대는 정산이다. **그 자리에서 런이 끝난다(E-16).** 시간을 야금야금 잃는 셈법이 아니라 판돈을 건 도박이다. 훈계는 한 마디도 안 한다.

그리고 무엇보다 — **80대 노인이 단소 들고 전력질주하는 그림이 웃기다.** 실패조차 재미있어야 다시 한다.

**톤 가드레일**: 폭력이 아니라 슬랩스틱이다. 피 없음, 데미지 수치 없음, 캐릭터는 3등신 SD. 타격음은 "딱!" 목탁 계열. 할아버지 대사는 훈계가 아니라 잔소리.
> `"이놈아!"` / `"어허!"` / `"내 효자손!"` / `"요즘 젊은 것들이!"`

## 5. 아이템 시스템

### 5.1 인터랙션 규칙 (핵심 UX)

```
플레이어 ─── 거리 ≤ 1.5m ───► 아이템
                              │
                              ▼
                    ┌─────────────────────┐
                    │ 아웃라인 발광 (2px) │
                    │ + 라벨 툴팁 표시     │
                    │ + 은은한 펄스 애니   │
                    └─────────────────────┘
                              │
                        마우스 hover
                              │
                              ▼
                    아웃라인 굵어짐(3px) + [E] 프롬프트
                              │
                        E 키 / 클릭
                              ▼
                          습득 (0.8s)
```

**아웃라인 = 골드 단일 (`#FFC83D`)**

상호작용 가능한 모든 대상은 **종류·조건·결과와 무관하게 동일한 골드 아웃라인**으로 표시한다.
습득 아이템도, 조사 대상도, 조건 미충족 오브젝트도, 훔치면 벌 받는 효자손도 전부 같은 금색이다.

| 상태 | 표현 |
|---|---|
| 근접 (≤1.5m) | 골드 아웃라인 2px + 라벨 툴팁 + 은은한 펄스 |
| hover | 골드 아웃라인 3px + `[E]` 프롬프트 |
| 조건 미충족 대상에 `E` | 아웃라인 1회 깜빡임 + 사유 텍스트 (`"효자손이 필요하다"`) |

> **왜 색을 없앴나**
> v0.1은 5색 코드로 "이건 훔치는 거야"까지 UI가 미리 알려줬다. 친절하지만, 그건 **게임이 플레이어 대신 판단해주는 것**이다.
> 이 게임의 핵심 동사는 `Q`(관찰)다. 색이 답을 알려주면 관찰할 이유가 사라진다.
>
> 골드 단일은 **"여기 뭔가 있다"까지만 말하고 입을 다문다.** 그게 뭔지, 훔치는 건지, 대가가 뭔지는 플레이어가 다가가서 알아내야 한다.
> 도덕적 경고는 UI가 아니라 **결과**가 한다 — 효자손을 훔치면 3초 뒤 단소가 날아온다(O-14). 색깔 하나보다 훨씬 확실하게 배운다.
>
> 부수 효과로 학습 부담도 사라진다. 색 5개 외울 필요 없이 **"금색 = 만질 수 있음"** 규칙 하나면 끝. 3분짜리 게임에 색상 범례는 사치다.

### 5.4 시그니처 퍼즐 — "효자손 체인" 🪄

프로젝트의 **얼굴이 되는 퍼즐**. 튜토리얼이자 게임의 톤을 정의한다.

```
        🪑 벤치에 앉은 할아버지 (효자손 소지)
             ── 아웃라인: 골드 (3분기 전부 동일) ──
                     │
      ┌──────────────┼──────────────┐
      │              │              │
   [A] 훔치기      [B] 선물       [C] 말 걸기
      │         ※편의점 선행       │
      │        (매대 5지 선택,      │
      │         1회 한정 구매)       │
   +0s 즉시       +8s 소요       +15s 소요
   양심 -3        양심 +1        양심 +1
   효자손 획득   양갱이면 획득     효자손 획득
      │        오답 4종이면        │
      │        즉시 게임 종료(E-15)  │
      │              │              + 힌트: "3번 개찰구가
      │              │                오늘 아침부터 먹통이야"
      ▼           (정답만)           │
 🎋 단소 추격 발동   │              │
 (O-14, 10초)       │              │
 2대째 피격 시       │              │
 즉시 종료(E-16)     │              │
      │              │              │
      └──────────────┴──────────────┘
                     │
                     ▼
          🥤 자판기 하단 긁기 (QTE)
          마우스 좌↔우 드래그 3회, 리듬 판정
                     │
          ┌──────────┴──────────┐
       성공                  실패
       동전 500~1500          효자손 걸림, -5s, 재시도
          │
          ▼
   💳 교통카드 잔액에 즉시 자동 충전
      (별도 확인·발급 절차 없음. 주우면 채워진다)
          │
          ▼
   자판기 A / B / C(히든) 각 1회, 최대 3,000원
          │
          ▼
   ┌──────┴───────────────────┐
 잔액 ≥ 1,400              잔액 < 1,400
   │                          │
 개찰구 통과 가능        충전기(-12s) / 바닥 동전 /
                          역무실 사정 / 비상게이트
                              │
                      (전부 실패 → 부정승차 유혹 분기)
```

**요금 기준**: 개찰구 통과 1회 = **1,400원**. 시작 잔액이 1,400 미만인 시드(전체의 60%)에서만 이 체인이 강제된다.
잔액이 충분한 시드에서도 효자손은 여전히 가치 있다 — **여유 잔액 = E-14 "동전 부자" 조건**이고, 대화 루트는 개찰구 힌트를 준다.

**왜 이 퍼즐이 좋은가**
1. 한국인이면 누구나 아는 도시전설("자판기 밑에 동전 있다")을 메카닉화
2. 도덕적 분기 3개가 자연스럽게 발생 — 훈계 없이 플레이어가 스스로 선택
3. 정직한 루트가 **더 느리지만 정보를 준다** → 밸런스가 설교가 아니라 트레이드오프
4. **[A] 훔치기의 대가가 즉시 청구된다.** 8초 아끼려고 훔쳤는데 3초 뒤 단소가 날아온다.
   양심 페널티는 엔딩에서야 오지만, 단소는 그 자리에서 온다. 1대는 경고, 2대째는 런 종료(E-16) —
   **도덕이 아니라 판돈**
5. 동전 → 자동 충전으로 **획득과 사용 사이의 절차가 0**. "긁었다 → 채워졌다 → 통과했다"
   3박자로 끝나는 인과가 QTE의 쾌감을 그대로 개찰구까지 실어 나른다

| E-16 | **이놈이!** | 효자손 절도 후 단소에 2대째 피격 | 즉시 종료. "눈앞이 하얘졌다" |

> E-15·E-16은 `resolveEnding`의 우선순위 매칭을 타지 않는다 — `when`이 항상 거짓으로 고정돼 있고,
> 열차 출발 시 오검출되지 않도록 시스템이 그 순간 `{ t: 'END', endingId }`를 직접 발행한다.
> **단소 2대째는 더 이상 "완전 정지"가 아니다.** 예전엔 5대 누적 회수로 효자손만 잃고 게임은 계속됐지만,
> 지금은 2대째가 그 자리에서 런을 끝낸다(E-16). **벌은 주되 문은 닫지 않는다**는 원칙은 유지된다 —
> 1대는 경고로 끝나고, 감속은 도망치면 회복된다. 즉사가 허용되는 건 E-09 부정승차·E-11 에스컬레이터
> 참사·E-15 오답 선물·E-16 단소 2대째, 넷뿐이다. 전부 명백한 선택의 결과다.

### 6.3 엔딩 도감
클리어 후 **16칸 그리드 도감**. 미획득은 실루엣 + 힌트 한 줄.
> 예: E-12 → `"???" — 급할수록 돌아가라던 말, 진짜였을까`

**리텐션 설계**: 1회 플레이 3분 × 16엔딩 = 최소 48분 콘텐츠. 도감 완성이 곧 목표.

### 8.1 시간 예산표 (숙련자 기준)

> **의도적 적자 설계**: 표준 플레이(183s) > 제한시간(180s).
> 즉, **아무것도 모르면 반드시 진다.** 정보를 쌓아야만 이긴다. → 리플레이 강제.
> *v0.2에서 발매기 단계가 사라져 체인이 7초 짧아졌다. 적자 폭이 10s → 3s로 얇아졌으므로,
> 플레이테스트에서 승률이 너무 높게 나오면 **제한시간 180s → 170s**를 먼저 조정한다 (존 예산은 건드리지 않는다).*

### 8.1.1 효자손 루트별 실질 비용 ⚖️

**v0.2 밸런스의 핵심 표.** 절도가 가장 빠르지 않게 만드는 것이 목표다.

| 루트 | Z2 직접 소요 | 리스크 / 추가 비용 | **실질 총비용** | 양심 |
|---|---:|---|---:|:---:|
| **[A] 훔치기** | 35s | 단소 추격 최대 10s · 1대 피격 감속 -20%(회복 5%/s) · **2대째 피격은 즉시 런 종료(E-16)** | **35~45s (생존 시), 실패 시 런 종료** | -3 이하 |
| **[B] 선물** | **44s** | 편의점 구매 + 우회 0.3s (할아버지 길목이라 거의 공짜) | **44s** | +1 |
| **[C] 말 걸기** | 50s | 없음. **개찰구 힌트로 Z3에서 -20s 회수** | **30s** | +1 |

> **결론: 가장 정직한 루트가 가장 빠르다.** 단, 그건 *두 번째 플레이부터* 알게 된다.
>
> 첫 플레이의 플레이어에게 [A]는 "+0초, 즉시 획득"으로 보인다. 명백한 최적해처럼 생겼다.
> 그리고 3초 뒤 단소가 날아온다. **이 배신감이 곧 학습이고, 학습이 곧 재도전 동기다.**
>
> 설계 규칙: *유혹은 눈에 보이게, 대가는 겪어야 알게.* 이걸 UI 색깔로 미리 알려주면(v0.1의 🔴 레드) 이 학습 곡선이 통째로 사라진다.
>
> **v0.3 — [B] 43s → 44s.** 구매처가 Z1 노점에서 Z2 편의점으로 옮겨지며 Z2 구간이 1.1s 비싸졌다
> (우회 0.30s + 습득 0.8s). 대신 Z1 낭비 시나리오가 43s → 37.4s로 내려가 **한 판 전체로는 [B]가 싸졌다.**
> 좌표 근거는 MAP-LAYOUT §4.4·§14.4·§14.5.
>
> **[A]와의 마진은 4s → 3s.** "절도가 가장 빠르지 않다"는 여전히 성립하지만 여유가 1s 줄었다.
> 이 3s는 **편의점(24,27)이 진입점과 할아버지 벤치의 거의 일직선 위에 있다는 좌표 우연**에 기대고 있다.
> `OBJ-19`나 `ACT-02`를 옮기는 순간 이 표는 거짓이 된다 — MAP-LAYOUT §12 R2′ 참조.

### 9.3 상태 모델 (불변)

```ts
type GameState = Readonly<{
  timeLeftMs: number
  zone: ZoneId
  player: Readonly<{
    pos: Vec2
    stamina: number
    speedPenalty: number                     // 0.0 ~ 1.0, 단소 피격 누적. 실효속도 = base * (1 - speedPenalty)
  }>
  inventory: readonly (ItemId | null)[]      // length 3. 교통카드·동전은 슬롯 미점유
  cardBalance: number                        // v0.2: 동전은 여기로 직접 흡수. coins 필드 없음
  chase: Readonly<{                          // v0.3: O-14 단소 추격
    active: boolean
    remainingMs: number                      // 10_000 에서 감소
    hitCount: number                         // 2 도달 시 즉시 종료(E-16)
    swingCooldownMs: number
  }>
  scores: Readonly<{ conscience: number; style: number; knowledge: number }>
  flags: ReadonlySet<FlagId>                 // 'GRANDPA_ANGRY', 'WALLET_RETURNED' ...
  seed: number
}>

// 모든 변경은 새 객체 반환
const applyTimePenalty = (s: GameState, ms: number): GameState =>
  ({ ...s, timeLeftMs: s.timeLeftMs - ms })

// v0.2: 동전 습득 = 잔액 가산. 중간 단계 없음
const pickUpCoin = (s: GameState, amount: number): GameState =>
  ({ ...s, cardBalance: s.cardBalance + amount })

// v0.2: 단소 피격 — 감속 누적 상한 1.0, 양심 -1
const applyDansoHit = (s: GameState): GameState => ({
  ...s,
  player: { ...s.player, speedPenalty: Math.min(1, s.player.speedPenalty + 0.2) },
  chase:  { ...s.chase, hitCount: s.chase.hitCount + 1, swingCooldownMs: 1_500 },
  scores: { ...s.scores, conscience: s.scores.conscience - 1 },
})

// v0.2: 비피격 시 초당 5% 회복 — 도망치면 풀린다
const recoverSpeed = (s: GameState, dtMs: number): GameState =>
  ({ ...s, player: { ...s.player,
       speedPenalty: Math.max(0, s.player.speedPenalty - 0.05 * dtMs / 1000) } })
```

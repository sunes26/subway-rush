## 0. 고증 기준 — 조사 결과 반영

실제 서울 지하철 역사에서 가져온 것과, 의도적으로 버린 것.

| 항목 | 실제 | 게임 채택 | 근거 |
|---|---|---|---|
| 층 구성 | 지상 출구 → B1 대합실 → B2 승강장 | **그대로 채택** | 수직 하강이 Z4의 존재 이유 |
| 개찰구 위치 | 승강장 계단 **바로 앞**. 운임구역이 좁다 | **그대로 채택** | Z3 통과 = 되돌아갈 수 없음이 자연스러워짐 |

### 0.1 에스컬레이터 고증의 재해석

한국 에스컬레이터에는 **법으로 정해진 줄서기 규칙이 없다.** 1998년 한줄 서기 홍보 → 2007년 두줄 서기 전환 → 2015년 캠페인 중단. 30년간 정부가 방향을 두 번 바꿨고 지금은 아무 말도 안 한다.

그래서 남은 건 **관행**이다: 우측에 서고, 좌측은 급한 사람이 걸어 올라간다. 아무도 강제하지 않지만 대부분 지킨다.

> **설계적 함의**: O-03 에스컬레이터 인파벽은 "규칙 위반자"가 아니라 **"눈치 없는 사람"**이다.
> 그래서 해결 수단이 "신고"가 아니라 `"저기요"` 한 마디이고, 그래서 웃기다.
> 이 게임의 방해요소 중 유일하게 **가해자에게 악의가 없는** 케이스다. 톤을 여기에 맞춘다.

## 1. 좌표계 · 스케일 규약

### 1.1 좌표계

```
존별 로컬 좌표계. 원점 = 각 존 평면의 남서(좌하) 코너.
+X = 동(화면 오른쪽)   +Y = 북(화면 위쪽)   +Z = 상(고도)
단위: m. 그리드 스냅: 2m (타일 1칸 = 2m).
```

| 층 | 고도 Z | 존 |
|---|---:|---|
| L0 지상 | ±0 | Z1 |
| B1 대합실 | −6 | Z2 · Z3 · Z4 상부 |
| B2 승강장 | −20 | Z4 하부 · Z5 |

**카메라**: 2.5D 쿼터뷰 고정각. 존별 프레이밍 규칙은 §7.

### 1.2 축척 — 실측의 60%

실제 역 대합실 ~90m → 게임 58m. 실제 승강장 200m(10량) → 게임 128m(8량).

축척을 줄인 이유는 하나다. **3분 게임에서 이동은 콘텐츠가 아니다.** 이동은 판단과 판단 사이의 여백이어야지, 그 자체가 예산을 다 먹으면 안 된다.

### 1.3 이동 속도 — 맵 치수의 근거

모든 존 치수는 이 표에서 역산했다. **속도를 바꾸면 맵 전체를 다시 계산해야 한다.**

| 상태 | 속도 | 비고 |
|---|---:|---|
| 걷기 (기본) | **5.0 m/s** | 3등신 SD 기준 화면상 "빠른 걸음" |
| 스프린트 | 8.3 m/s | 이동시간 −40% (GDD §2 준수) |
| 계단 하강 | 3.5 m/s | |
| 계단 2단씩 | 5.5 m/s | 넘어질 확률 25%, −3s 이득 |
| 에스컬레이터 정지 탑승 | 1.5 m/s | |
| 에스컬레이터 좌측 보행 | 5.5 m/s | 인파벽 없을 때만 |
| 군중 밀집 구간 관통 | 2.5 m/s | 마스크(ITM-06) 시 3.5 m/s |
| 감속 100% (단소 5피격) | 0 | 2초 완전 정지 |

**검산 규칙**: `존 최소 예산 = 최단 경로 길이 ÷ 속도 + 필수 상호작용 시간 + 존 전환 마찰 2s`

### 3.3 신호등 — Z1의 유일한 진짜 판단

| 파라미터 | 값 |
|---|---:|
| 주기 | 30s (녹 12s / 적 18s) |
| 기대 대기 | 5.4s |
| 최악 대기 | 18s |
| **잔여시간 표시기** | 신호등 폴에 부착. `Q`(관찰)로 판독 가능 |

잔여시간 표시기는 실제 서울 횡단보도에 달려 있는 물건이고, 게임에서는 **"지금 스프린트하면 건널 수 있는가"**를 계산할 수 있게 해준다. Z1에서 `Q`를 쓸 이유를 만드는 유일한 오브젝트다.

> 이게 튜토리얼이다. 설명 없이, 첫 30초 안에, **"관찰하면 시간을 아낀다"**를 한 번 겪게 한다.

### 3.4 예산 검산

| 시나리오 | 계산 | 결과 | GDD §8.1 |
|---|---|---:|---:|
| **최소** | 62m ÷ 8.3(스프린트) = 7.5s + 녹신호 즉시 + 전환 2s | **9.5s** | 12s ✓ |

| **낭비 (v0.2)** | ~~19.8 + 노점 왕복 1.8 + 구매 3 + 습득 0.8 + 전단지 5 + 적신호 풀 12.6~~ | ~~43s~~ | 35s (초과) |
| **낭비 (v0.3)** | 19.8 + 전단지 5 + 적신호 풀 12.6 | **37.4s** | 35s (초과) |

> *(v0.2 행의 43s는 항목 합과 0.8s 어긋나 보였는데, 빠져 있던 항이 붕어빵 **습득 0.8s**였다. 위에 복원했다.)*
>
> 낭비 시나리오는 여전히 예산을 넘는다. 의도적이다 — Z1에서 다 해먹으면 Z5에서 죽는 게 이 게임의 척추다.
> **v0.3에서 노점 구매가 Z2 편의점으로 넘어가며 −5.6s.** 초과 폭이 8s → 2.4s로 줄었다.
> 이제 Z1에서 시간을 흘릴 수 있는 경로는 **전단지 피격과 적신호 두 가지뿐**이고, 둘 다 플레이어가
> 물건을 사려다 잃는 게 아니라 *가만히 있다 당하는* 손실이다. 즉 Z1은 '유혹 구간'에서 **'통과 구간'**이 됐다.
> → v0.2의 완화책(전단지 순찰 x 18~30 과 노점 x=14 분리 배치)은 **더 이상 밸런스 근거가 아니다.**
> 배치는 그대로 두되(고증), 조합 리스크가 사라졌으므로 §12 R2를 재평가할 것.
>
> **부작용 주의**: Z1이 통과 구간이 되면 §3.3 튜토리얼("관찰하면 시간을 아낀다")을 신호등 하나가 혼자 짊어진다.
> 신호등 관찰 이외의 학습 계기가 Z1에 남아 있는지 플레이테스트에서 확인해야 한다.

## 4. Z2 — 대합실 (B1) · 56 × 30 m

### 4.1 설계 원리 — "최단선과 벽면"

```
진입점(북서) ──────────── 최단 직선 53.9m ────────────► 개찰구(동측 중앙)

이 직선 위에 있는 것 : 종합안내도 · 아주머니 2인조 · 할아버지 벤치(3m 이탈)
이 직선 밖에 있는 것 : 자판기 3대 · 충전기 · 우산 · 신문 · 편의점 · 화장실 · 유실물
```

**모든 자원 획득은 우회 비용이다.** 그리고 최단선 위에는 **시간을 뺏는 것들만** 놓았다.
아주머니 2인조가 정중앙에 배회하는 이유가 이것이다 — 최단 경로를 쓰려면 그들을 통과해야 하고, 피하려면 이미 우회한 셈이 된다.

할아버지 벤치만 예외적으로 최단선에서 **3m 떨어져 있다.** 지나가다 반드시 보이지만, 다가가려면 발을 멈춰야 한다. 시그니처 퍼즐이 "선택"이 되려면 이 거리가 필요하다. 0m면 자동 발동이고, 15m면 못 본 채 지나간다.

### 4.4 효자손 체인 — 좌표 검산

GDD §8.1.1의 루트별 비용표가 **맵에서 실제로 성립하는지** 검증한다. 이게 이 문서의 핵심 검산이다.

```
진입(4,28) ──40.2m/8.0s──► 할아버지(42,15) ──22.4m/4.5s──► 자판기B(22,5)
                                                              │ QTE 3s
                                              ┌───────────────┘
                                              ▼
                                     자판기A(11,5) ──45.9m/9.2s──► Z3(56,14)
                                       11m/2.2s + QTE 3s
```

| 루트 | 이동 | QTE | 분기 비용 | **Z2 총합** | GDD §8.1.1 | 판정 |
|---|---:|---:|---:|---:|---:|:---:|
| **[A] 훔치기** | 23.9s | 6.0s | +0s (즉시) | **34.9s** | 35s | ✓ |
| **[B] 선물** | 23.9 **+0.3**s | 6.0s | +8s (증정 연출) **+0.8**s 습득 | **44.0s** | ~~43s~~ → **44s** | ✓ |
| **[C] 말 걸기** | 23.9s | 6.0s | +15s (인생 이야기) | **49.9s** | 50s | ✓ |

**좌표가 밸런스 표와 오차 0.1s 내로 일치한다.** 맵을 이 수치에 맞춰 역산했으므로 당연하지만, 반대로 말하면 — **이 좌표를 옮기면 GDD §8.1.1이 즉시 거짓말이 된다.** 배치 변경 시 이 표를 반드시 다시 계산할 것.

> **v0.3 — [B]만 +1.1s.** 선물을 사는 자리가 Z1 노점에서 Z2 편의점(24,27)으로 옮겨졌다.
>
> **우회 0.3s는 §14.5의 올바른 공식으로 계산했다.** §4.3 표의 "+12m = 2.4s"를 그대로 쓰면 안 된다 —
> 그 열은 최단선까지의 수직거리×2라 경유점이 진행 방향 앞쪽일 때 과대계상된다(§14.5).
> 실제로 [B]의 목적지는 Z3 진입선이 아니라 **할아버지 벤치(42,15)**이고, 편의점은 그 길목에 있다:
>
> ```
> 우회 = |진입→편의점| + |편의점→할아버지| − |진입→할아버지|
>      = 20.02 + 21.63 − 40.16 = 1.50m → 0.30s     (v=5.0 m/s)
> ```
>
> 편의점(24,27)은 진입(4,28)과 할아버지(42,15) 사이에 거의 일직선으로 놓여 있다. **거의 공짜로 지나친다.**
> 여기에 선물 습득 0.8s를 더해 **+1.1s**. Z1에서는 노점 구매가 통째로 빠져 **−4.0 ~ −5.6s**
> (§3.4 표기 기준 5.6s, §14.5 공식으로 왕복을 0.22s로 고쳐 잡으면 4.0s).
> 한 판 전체로는 [B]가 오히려 **3~4.5s 싸졌다.** 비싸진 것은 Z2 구간 하나뿐이다.
>
> **Z2 존 예산(GDD §8.1 "효자손 체인 완주" 표준 48s) 여유 있게 통과** — 44.0s.
> §8.1.1의 루트별 목표치만 43s → 44s로 고쳤다. [A] 하한 47s와의 마진도 4s → 3s로, 거의 유지된다.
>
> ⚠ **단, 이 계산의 전제는 "편의점이 할아버지 길목에 있다"는 것 하나다.**
> `OBJ-19`나 `ACT-02`의 좌표를 옮기면 0.30s는 즉시 무효가 된다. 배치 변경 시 위 3항 공식을 다시 돌릴 것.

**자판기 C 추가 비용**: 자판기A(11,5) → C(52,3) = 41.0m = 8.2s + QTE 3s = **+11.2s**
→ E-14 "동전 부자"는 11초짜리 도박이다. 3,000원 달성하려면 3대 전부 성공해야 하므로, 꽝(0원) 시드가 하나만 나와도 11초를 버린다. 히든 엔딩에 맞는 무게다.

### 7.4 타이머가 줄을 고른다

```

### 14.4 §4.4 효자손 체인 표의 누락 열

실측 총합이 GDD §8.1.1보다 **일관되게 4.1s 부족**했다. 원인은 §4.4 표에 **고정 오버헤드 열이 빠진 채 합계에만 반영**돼 있었기 때문이다 (23.9 + 6.0 + 0 = 29.9인데 34.9로 적혀 있었다).

| 루트 | 이동(실측) | QTE | 분기 | **고정 오버헤드** | 총합 | GDD §8.1.1 |
|---|---:|---:|---:|---:|---:|---:|
| [A] 훔치기 | 24.84 | 6.0 | +0 | **+4.4** | **35.2s** | 35 ✓ |
| [B] 선물 (v0.3) | 24.84 **+0.30** | 6.0 | +8 | **+5.2** | **44.3s** | 44 ✓ |
| [C] 말 걸기 | 24.84 | 6.0 | +15 | **+4.4** | **50.2s** | 50 ✓ |

> **고정 오버헤드 4.4s = 아이템 습득 0.8s × 3 + 존 전환 2.0s.**
> 이 열을 명시하면 세 루트 전부 GDD와 오차 0.2s로 맞는다. **표가 틀렸던 것이지 맵이 틀린 게 아니었다.**

> 이 오차는 v0.2에서도 있던 것(43.2 vs 42.9)이라 새로 생긴 문제가 아니다 — 이동 실측 24.84 vs 표기 23.9의 차다.

### 14.5 우회 비용 계산법 오류

§4.3의 "이탈(왕복)" 열은 **최단선까지의 수직거리 × 2**로 계산돼 있다. 이건 경유점이 플레이어 **옆**에 있을 때만 맞다. 경유점이 진행 방향 **앞쪽**에 있으면 실제 추가 거리는 훨씬 작다.

> **실측 예**: Z1 붕어빵 노점 우회 = **+1.09m** (문서 표기 +9m).
> 노점이 진행 경로에서 4m 옆이지만 앞쪽에 있어, 경유해도 총 이동은 1.09m밖에 안 는다.

**올바른 공식**: `우회 = |현재→경유| + |경유→목적| − |현재→목적|`
§4.3·§3.2의 이탈 열은 이 공식으로 재계산해야 한다. **다행히 §4.4 효자손 체인은 애초에 구간별 실거리로 계산했으므로 영향 없다.**

> **v0.3 — 이 공식이 실제로 밸런스를 뒤집은 첫 사례.**
> `OBJ-19` 편의점의 표기값 +12m(2.4s)를 그대로 [B] 루트에 더하면 46.1s가 나와 §8.1.1을 3s 넘긴다.
> 올바른 공식으로는 **+1.50m(0.30s)**다 — 편의점(24,27)이 진입(4,28)과 할아버지(42,15)의 거의 일직선 위에 있어서다.
> 결과는 44.0s로 예산 안이다. **표기값을 믿었으면 있지도 않은 초과를 잡겠다고 증정 연출 8s를 깎을 뻔했다.**
>
> §4.3 이탈 열 전체 재계산은 아직 안 했다. 최소한 **[B] 루트 경유점만은** 위 공식으로 계산된 값이다.

Z1 이 "버스에서 내려 역으로 들어가는 짧은 복도"에서 **거리**가 됐다.
빌더는 `tools/hq_street.py`(형상) · `game/src/render/cars.ts`(차량).

### 16.1 가로 단면 (남 → 북)

```
y 12.6~1.6   남측 건물 7동      안길이 11.0 · 앞면 y12.6
y 12.6~16.0  남측 인도          배경. **충돌 없음** — 슬랩도 없어 여기까지는 못 간다
y 16.0~22.0  차도               `Z1-ROAD` 슬랩. 걸어 들어갈 수 있다
y 22.0~34.0  북측 인도          플레이어 주 동선
y 34.0~45.0  북측 건물 7동      안길이 11.0 · 앞면 y34.0, x −1.6~12.0 은 역 출입구라 비운다
가로 x 범위  −66.0 ~ 12.0
이면도로     x −31.4 ~ −22.6 (남북). 횡단보도가 이것을 가로지른다
횡단보도     x −31.0 ~ −23.0 · y 23.9 ~ 31.1
```

건물은 저층부 4.20 + 기준층 3.30, 층마다 슬래브 띠 0.22 를 **둘레 전체**에 두른다
(앞면에만 두르면 옆면이 민짜로 남는다). 옥상 파라펫 0.75.

### 16.2 신호등 — 교차로 하나를 신호 하나로 돌린다

보행등 2기: 횡단보도 서단 `x −31.70` (등면 +x) · 동단 `x −22.30` (등면 −x).
등 하단 z 2.55 · 등면 반지름 0.15. 차량등은 주 차도 양방향.

**등면 방향은 실측으로 잡는다.** 처음에 교차 축을 남북으로 읽어 한 번 통째로 뒤집혔다 —
이면도로가 남북이고 **횡단은 동서**다.

```
보행 녹색 → 이면도로 차 정지 · 주 차도 차 주행
보행 적색 → 이면도로 차 주행 · 주 차도 차 정지
위상 전환 2.2초 전 = 황색 — 지금 달리는 쪽이 미리 선다
```

### 16.4 Z1 은 벽 대신 **결과**로 막는다

**삭제한 충돌체 3개** — 부록 A 의 Z1 항목에서 빠졌다.

| ID | 무엇 |
|---|---|
| `LIGHT-BLOCK` | 적신호 동안 횡단보도를 막던 동적 벽 |
| `Z1-CURB-S` | 차도 연석 (y 21.8~22.0) |
| `Z1-SIDEROAD-S/N` | 횡단보도 밖 이면도로 벽 |

대신 **차체에 닿으면 스폰(−58, 24)으로 되돌아간다.** 시간은 안 깎는다 — 26 m 를 다시
걷는 것이 이미 대가라 페널티를 겹치면 두 번 벌주는 꼴이다. 재판정 쿨다운 1.2초.
판정 상자는 1.70 × 4.20 m(모델 실치수 1.88 × 4.46 보다 작게 — 스치는 걸로는 안 걸린다).

겹침 계산은 `game/src/systems/roadHazard.ts` 에 순수 함수로 있다. 차는 열차와 달리
시간의 순수 함수가 아니라(앞차·신호를 보고 매 프레임 적분) 판정 자체는 렌더 루프에 둔다.

**신호등 폴(`OBJ-02`, (−32.6, 22.6) 0.4 × 0.4)은 그대로 막는다.** 벽을 걷었다고 물건까지
없앤 것은 아니다 — 유닛 테스트가 이 경계선을 지킨다.

HUD 문안도 금지에서 경고로 바꿨다: `정지 · 적신호` → `적신호 · 차 주의`.

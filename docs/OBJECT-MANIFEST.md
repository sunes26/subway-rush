### A-1. ACT-02 할아버지 — 구현 상세 (v0.2 최대 변경점)

이 액터 하나가 **정적 NPC → 대화 분기 → 추격 AI → 근접 공격**을 전부 가진다.
단일 액터 중 구현 난이도 최고. **P1 착수 시 가장 먼저 잡을 것.**

**상태 머신**

```
   IDLE (벤치 착석)
     │
     ├── [B] 선물 / [C] 대화 ──► GIVE ──► IDLE (mood: friendly)
     │
     └── [A] 절도 ──► DRAW (단소 발도 0.6s) ──► CHASE
                                                 │
                    ┌────────────────────────────┤
                    │                            │
              거리 ≤ 1.2m                   remainingMs = 0
              && cooldown = 0                또는 Z3 진입
                    │                            │
                    ▼                            ▼
                 SWING ──► 명중 시            RETURN (벤치 복귀)
                 hitCount++                       │
                 speedPenalty += 0.2              ▼
                 conscience −1                  IDLE
                    │
              hitCount = 5
                    ▼
              SEIZE (완전 정지 2s + 효자손 회수)
                    │
                    ▼
                 RETURN
```

**파라미터 (튜닝 대상)**

| 키 | 값 | 비고 |
|---|---:|---|
| `chase.durationMs` | 30,000 | Z3 진입 시 즉시 0 |
| `chase.moveSpeed` | 플레이어 걷기 × 1.0 | 스프린트로만 이탈 가능 |
| `swing.range` | 1.2 m | 상호작용 반경(1.5m)보다 좁게 |
| `swing.cooldownMs` | 1,500 | 연타 즉사 방지 |
| `hit.speedPenalty` | +0.20 | 상한 1.0 |
| `hit.conscience` | −1 | 누적 |
| `recovery.rate` | −0.05 / s | **비피격 시 회복** — 도망치면 풀림 |
| `seize.threshold` | hitCount 5 | 완전 정지 2s + 효자손 회수 |

> **SEIZE는 게임오버가 아니다.** 효자손만 잃고 게임은 계속된다. 3분 게임에서 방해요소 즉사는 재도전 의욕을 꺾는다.
> **톤 가드레일**: 3등신 SD · 데미지 수치 미표시 · 무혈 · "딱!" 목탁 SFX · 대사는 훈계 아닌 잔소리(`"이놈아!"` `"내 효자손!"`).

### F-1. 상태 소유권 규칙

```
시간 감산은 SYS-01 단일 경유. 다른 곳에서 timeLeft 직접 수정 금지.
잔액 변경은 SYS-04 단일 경유. 동전·충전기·요금 차감 전부 여기로.
모든 스토어는 불변 업데이트 — 새 객체 반환, 원본 변형 금지.
```

```ts
// v0.2 상태 모델 (발췌)
type GameState = Readonly<{
  timeLeftMs: number
  player: Readonly<{ pos: Vec2; stamina: number; speedPenalty: number }>
  inventory: readonly (ItemId | null)[]   // length 3. 카드·동전은 미점유
  cardBalance: number                     // coins 필드 없음
  chase: Readonly<{ active: boolean; remainingMs: number
                    hitCount: number; swingCooldownMs: number }>
  scores: Readonly<{ conscience: number; style: number; knowledge: number }>
  flags: ReadonlySet<FlagId>
  seed: number
}>

// 동전 습득 = 잔액 가산. 중간 단계 없음
const pickUpCoin = (s: GameState, amount: number): GameState =>
  ({ ...s, cardBalance: s.cardBalance + amount })

// 단소 피격 — 감속 상한 1.0, 양심 −1
const applyDansoHit = (s: GameState): GameState => ({
  ...s,
  player: { ...s.player, speedPenalty: Math.min(1, s.player.speedPenalty + 0.2) },
  chase:  { ...s.chase, hitCount: s.chase.hitCount + 1, swingCooldownMs: 1_500 },
  scores: { ...s.scores, conscience: s.scores.conscience - 1 },
})

// 비피격 시 초당 5% 회복 — 도망치면 풀린다
const recoverSpeed = (s: GameState, dtMs: number): GameState =>
  ({ ...s, player: { ...s.player,
       speedPenalty: Math.max(0, s.player.speedPenalty - 0.05 * dtMs / 1000) } })
```

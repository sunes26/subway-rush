## 0. P0의 정의 — "이것만 있어도 게임이다"

P0의 목표는 재미가 아니다. **끝까지 돌아가는 것**이다.

> **게이트 조건 (GDD §10 원문)**: 처음부터 끝까지 플레이 가능해야 함.

구체화하면 이렇다 — 플레이어가 브라우저를 열고, 버스에서 내려서, 걸어서, 개찰구를 골라서, 지하로 내려가서, 열차를 타거나 놓치고, 엔딩 화면을 본 뒤, 재시작할 수 있어야 한다. 그 사이 어떤 단계에서도 **막히거나(soft-lock) 튕기지 않아야** 한다.

P0에서 "재미"를 담당하는 유일한 요소는 **개찰구 선택 1회**다. 나머지는 전부 그 선택을 성립시키기 위한 배관이다.

### 0.1 P0 스코프 — 있는 것 / 없는 것

| | 있음 | 없음 (P1 이후) |
|---|---|---|
| **이동** | WASD 걷기 · Shift 스프린트 · 스태미너 | 슬라이딩(Space), 넘어짐 |
| **카메라** | 쿼터뷰 추적 + 마우스 오빗/줌 | Q 관찰 모드 |
| **월드** | 5개 존 전부, 연속 공간, 충돌 | 상점/화장실 내부 진입 |
| **시간** | 180초 타이머 + LED HUD + 4단계 연출 | — |
| **개찰구** | G1~G6, 시드로 정상 1개, 단서 2종(램프·LED) | 마모도, 앞사람 관찰, 역무원 순찰 |
| **요금** | 잔액 체크(1,400원), 태그 판정 | 동전, 자판기, 충전기, 효자손 |
| **승강장** | 열차 도착 → 정차 → 문 열림 → 탑승 → 문 닫힘 | 대기줄, 하차 인파, 스크린도어 돌파 |
| **엔딩** | E-01 아슬아슬 탑승 · E-06 다음 열차 | 나머지 12종, 도감 |
| **NPC** | 없음 | 할아버지, 아주머니, 군중, 역무원 |
| **아이템** | 없음 | 14종 전부 |
| **사운드** | 없음 (P2) | — |

### 0.2 P0에서 **의도적으로 무력화**한 규칙

| 규칙 | GDD 원본 | P0 처리 | 근거 |
|---|---|---|---|
| 초기 카드 잔액 | 0~2,200원 랜덤 (60% 시드가 요금 미달) | **1,600 / 2,200원만** (항상 통과 가능) | P0엔 충전 수단이 **하나도 없다.** 잔액 부족 시드 = 즉시 소프트락. 잔액 로직은 구현하되 시드 범위만 좁힌다 → P1에서 자판기 붙이는 순간 한 줄로 원복 |
| 제한시간 | 180s (표준 플레이 183s, 의도적 적자) | **180s 유지** | P0엔 아이템 우회가 없어 실제 소요 ~95s. 적자 설계는 P1 콘텐츠가 들어와야 성립한다. P0에서 시간을 줄이면 "왜 졌는지 모르는 실패"가 된다 |
| 엔딩 판정 | 14종 우선순위 배열 | 배열 구조는 **그대로**, 항목만 2개 | 판정기를 P0에서 완성해두면 P1~P2는 데이터만 추가 |

## 2. 기능 명세

### 2.1 F-01 · 플레이어 이동

**입력**: `W A S D` (카메라 기준 상대 이동) · `Shift` 홀드 스프린트

| 파라미터 | 값 | 출처 |
|---|---:|---|
| 걷기 속도 | 5.0 m/s | MAP §1.3 |
| 스프린트 속도 | 8.3 m/s | MAP §1.3 |
| 계단 하강 | 3.5 m/s | MAP §1.3 |
| 에스컬레이터 정지 탑승 | 1.5 m/s | MAP §1.3 |
| 가감속 | 도달 시간 0.12s (지수 감쇠) | 신규 — 조작감 |
| 회전 보간 | 14 rad/s | 신규 |
| 캡슐 반경 | 0.32 m | 3등신 SD 기준 |
| 스태미너 | 최대 100 · 스프린트 −22/s · 회복 +14/s (1.0s 지연) | 신규 |

**규칙**
- 스태미너 0이면 스프린트 불가, 30 이상 회복해야 재사용 (플리커 방지).
- 이동은 **XY 평면**(월드 수평)에서 계산하고, Z(고도)는 지면 샘플링으로 결정한다 → 경사면에서 속도가 느려지지 않는다.
- 입력이 없으면 즉시 감속(0.09s). "미끄러지는 느낌"은 P0에서 금지.

**성공 기준**: 5.0 m/s로 10m를 2.00±0.05s에 이동. 벽에 45°로 밀어붙일 때 끼이지 않고 미끄러진다.

### 2.2 F-02 · 카메라

2.5D 쿼터뷰. **고정각이되 플레이어를 따라간다** (MAP §2: 존 전환 = 카메라 팔로우).

| 항목 | 값 |
|---|---|
| 투영 | Perspective FOV 38° (직교보다 깊이감 유리, 쿼터뷰 왜곡은 FOV로 억제) |
| 기본 피치 | −34° |
| 기본 요 | 존별 프리셋 (MAP §7) — Z1·Z2 −20° / Z3 0° / Z4 −35° / Z5 +12° |
| 거리 | 존별 12~30m |
| 추적 | 위치 지수 보간 λ=6.0, 선행 오프셋 = 속도 × 0.28s |
| 마우스 우클릭 드래그 | 요 ±45° / 피치 −20~−60° 수동 오빗 (놓으면 2.5s 뒤 프리셋 복귀) |
| 휠 | 거리 ±40% |

**존별 프레이밍**: 존 경계를 넘으면 목표 요/거리가 1.2s에 걸쳐 보간된다. **컷 전환 없음** — 3분 게임에 로딩/컷은 사망(MAP §2).

**Z3 특례**: 게이트 뱅크 6개가 **반드시 한 화면에 전부** 들어와야 한다 (MAP §5.4 — "정보를 전부 보여준 뒤에 선택시킨다"). 카메라 거리를 y범위 6~26m가 화면 세로 70% 안에 들도록 계산해 고정.

**성공 기준**: Z3 진입 시 G1~G6 램프 6개가 동시에 화면 내. 벽 뒤로 카메라가 파고들지 않는다.

### 2.3 F-03 · 월드 · 충돌

MAP-LAYOUT **부록 A 좌표를 단일 진실 원천**으로 삼는다. 좌표는 코드에 하드코딩하지 않고 `data/world.ts` 한 곳에 둔다.

**층 고도**: L0 ±0 / B1 −6 / B2 −20 (MAP §1.1)

**충돌 모델**: 축 정렬 박스(AABB) 리스트 + 원기둥(기둥). 메시 충돌 없음.
- 근거: 맵이 전부 직교 격자(2m 스냅)로 지어졌다. 삼각형 충돌은 P0에 과잉이고 디버깅이 어렵다.
- 경사(계단·에스컬레이터·출구계단)는 **경사 램프 볼륨**으로 별도 처리 — 볼륨 안에 있으면 z를 선형 보간.

**존 판정**: 플레이어 world.x 기준 구간 매칭.

| 존 | x 범위 | 층 |
|---|---|---|
| Z1 | −64 ~ 12 | L0 (출구계단 0~9에서 하강) |
| Z2 | 0 ~ 56 | B1 |
| Z3 | 56 ~ 72 | B1 |
| Z4 | 72 ~ 120 | B1 → B2 |
| Z5 | 78 ~ 206 | B2 |

> Z1/Z2와 Z4/Z5는 x가 겹친다. 층(z)으로 구분한다.

**성공 기준**: 5개 존 전부 도보로 도달 가능. 맵 밖으로 나가는 경로 0개. 바닥 뚫림 0회.

### 2.4 F-04 · 타이머 · HUD

**타이머**: 180.0s에서 감소. 단일 소스(`timeLeftMs`)이며 모든 페널티는 이 값에만 가산한다.

| 잔여 | 색 | 연출 | 출처 |
|---|---|---|---|
| 180~60s | `#F5F5F0` | 정적 | GDD §7.2 |
| 60~30s | `#FFC83D` | 초당 펄스 | GDD §7.2 |
| 30~10s | `#FF8A3D` | 심박 진입 (P0은 시각만) | GDD §7.2 |
| 10~0s | `#E5484D` | 화면 가장자리 비네팅 | GDD §7.2 |

**HUD 구성 (P0)**

```
┌─────────────────────────────────────────────────────┐
│  ▶ 신도림 방면 열차 도착              ⏱ 01:23       │  LED 전광판
├─────────────────────────────────────────────────────┤
│                                                     │
│                   [ 게임 화면 ]                     │
│                                                     │
├──────────────┬──────────────────┬───────────────────┤
│  ZONE  Z2    │  💳 잔액 1,600원  │   ▮▮▮▮▮▯ 스태미너  │
└──────────────┴──────────────────┴───────────────────┘
```

- 잔액 ≥1,400 흰색 / <1,400 적색 + 미세 진동 (GDD §7.2). P0에선 항상 흰색이지만 **코드는 양쪽 다** 구현한다.
- 미니맵·인벤·양심 게이지는 P0 미포함 (자리만 비워둔다).

**성공 기준**: 실시간 대비 타이머 오차 60초당 ±0.1s 이내. 탭 백그라운드 전환 후 복귀 시 시간이 순간 점프하지 않는다.

### 2.5 F-05 · 개찰구 (O-01) — **P0의 유일한 게임플레이**

**구성**: G1(y6) G2(y10) G3(y14) G4(y18) G5(y22) G6(y26, 우대용 0.9m). 게이트 본체 x 60.3~61.7. (MAP 부록 A)

**시드 규칙 (P0)**
- 정상 게이트 = 1~6 중 1개 (15% 확률로 2개 — GDD §8.3).
- G6(우대용)은 **고장 시드 대상에서 제외**되지 않는다. P0엔 캐리어가 없어 G6의 특례 이유가 없다.

**단서 (P0은 2종)**

| 단서 | 표현 | 비용 |
|---|---|---:|
| ① 램프 색 | 게이트 상단 표시등 — 정상 `#00A84D` ▲ / 고장 `#E5484D` ✕. z −3.95에서 발광 | 0s |
| ④ 안내 LED | `OBJ-23` 스크롤 텍스트 `"3번 게이트 점검중"`. **60% 시드에서만 표시** (GDD §5.4) | 0s |

> 마모도(`Q` 필요) · 앞사람 통과(군중 필요) · 할아버지 힌트(NPC 필요)는 P1.
> P0에서 단서는 램프만으로 충분하다 — 대신 **램프는 절대 거짓말하지 않는다.**

**태그 판정**

```
플레이어가 게이트 통로 진입 (x 59.8~60.3, y ±폭/2)
        │
        ▼
  자동 태그 시도 (별도 키 입력 없음 — 실제 개찰구처럼)
        │
   ┌────┴─────────────────────┐
정상 & 잔액≥1400          그 외
   │                          │
 "삑" 게이트 플랩 열림      플랩 잠김(물리적 벽)
 잔액 −1,400               ├ 고장:    −8s · 1.6m 후퇴 · 적색 플래시
 통과 2.0s                 └ 잔액부족: −6s · 제자리       [P0 미발생]
   │                          │
 운임구역 진입 (x≥62)      3.0s 쿨다운 후 재시도 가능
 ★되돌아갈 수 없음
```

- **쿨다운 3.0s**: 없으면 플레이어가 6개 게이트에 몸을 비비며 무작위 대입한다. 관찰을 강제하는 최소 장치.
- **비가역**: x≥62 진입 후 Z2로 되돌아갈 수 없다 (MAP §0 — 실제 역 구조 채택).

**성공 기준**: 정상 게이트 통과 성공률 100%. 고장 게이트 통과 성공률 0%. 오답 1회당 정확히 8.0s 차감. 6개 전부 시도해도 소프트락 없음.

### 2.6 F-06 · 수직 이동 (Z4)

3레인. P0은 2개만 살아있다.

| 레인 | y | 속도 | P0 |
|---|---|---:|---|
| 에스컬레이터 | 1.35~3.05 | 1.5 m/s (탑승 시 자동 이송) | ✅ |
| 계단 | 4.20~9.20 | 3.5 m/s (직접 조작) | ✅ |
| 엘리베이터 | x96~98.4, y9.6~12 | — | 🔒 잠김 (벽) |

**트레이드오프**: 사면 27.96m 기준 — 에스컬레이터 18.6s(조작 불필요) vs 계단 8.0s(직접 이동, 스태미너 소모 없음). **계단이 명백히 빠르다.** 이건 의도다 — P1에서 계단에 물청소(O-05)를, 에스컬레이터에 인파벽(O-03)을 붙이면 대칭이 깨지며 선택이 생긴다. P0은 그 골격만 세운다.

**성공 기준**: 두 레인 모두 B2(z−20) 착지. 에스컬레이터 위에서 입력 없이도 하강. 경사면에서 캐릭터가 떨리지 않는다.

### 2.7 F-07 · 승강장 · 열차 · 탑승 판정 (Z5)

**열차 스케줄** (t = 시작 후 경과, 총 180s)

| t | 이벤트 |
|---:|---|
| 0s | 게임 시작. LED: `"신도림 방면 열차 도착 03:00"` |
| 168.0s | 열차 진입 시작 (x 320 → 정차위치, 6.0s 감속) |
| 172.0s | 정차 완료. **안전문 + 차문 열림** (1.2s 애니) |
| 177.0s | 3초 경고음 + 문틀 점멸 (GDD O-12) |
| 180.0s | **문 닫힘 시작** (1.2s) |
| 181.2s | 완전 폐쇄 → 판정 확정 |
| 182.0s | 출발 |

> 타이머 0 = 문이 **닫히기 시작**하는 시점. GDD §1.1의 "문이 닫히기까지"를 문자 그대로 구현한다.
> 즉 **0초에 도착해도 탈 수 있다.** 1.2초의 자비가 E-01의 카타르시스를 만든다.

**열차 제원** (MAP 부록 A): 8량 × 16m = 128m. 차체 y12.42~15.58. 바닥 z−20.0(승강장 동일고). 가동문 32개소 — `x = 78 + 16k + {2,6,10,14}`, k=0..7. 개구 1.60m.

**탑승 판정**

```
조건 ①  문 상태 ∈ {열림, 닫히는중}
조건 ②  플레이어 중심이 어떤 문의 개구 사각형 내부
         x ∈ [doorX − 0.8, doorX + 0.8]
         y ∈ [11.6, 13.2]            (안전문 12.15 ~ 차체 앞면 12.42 관통)
조건 ③  플레이어가 +y 방향 입력 유지 중 (사고 탑승 방지)
        │
        ▼
   탑승 확정 → 입력 차단 · Board 애니 · 카메라 차내 전환 1.0s → 엔딩
```

- 문이 닫히는 중 진입 시에도 **판정은 통과**시킨다. 실패는 문 폐쇄 완료 시점에 확정된다.
- P0에서 안전문은 차문과 **완전 동기**로 동작한다 (별도 로직 없음).

**성공 기준**: 32개 문 전부에서 탑승 가능. 문 닫힌 뒤 진입 시 탑승 불가. 열차 측면(문 아닌 곳)으로 진입 불가.

### 2.8 F-08 · 엔딩 판정기

**구조**: 우선순위 내림차순 조건식 배열, 위에서부터 첫 매치 채택 (GDD §9.4). **P0에서 이 구조를 완성해 둔다** — P1~P2는 배열에 항목만 추가.

```ts
[
  { id: 'E-01', priority: 10, when: { boarded: true } },
  { id: 'E-06', priority:  0, when: { boarded: false } },   // fallback
]
```

| 엔딩 | 조건 | 대사 (GDD 부록 B) | 톤 |
|---|---|---|---|
| **E-01 아슬아슬 탑승** | 탑승 성공 | `"…겨우 탔다."` | 기본 성공 |
| **E-06 다음 열차** | 시간 초과 | `"5분 늦는다고 세상 안 무너져."` | **온화한 실패. 조롱 금지** (GDD §11) |

**E-06 규칙 (GDD §11 리스크 대응)**: 실패 화면에서도 **힌트 1줄을 반드시 제공**한다.
> 예: `"게이트 위 램프가 초록이면 살아있는 거다."`

**엔딩 화면**: 대사 + 잔여 시간 + 시드 번호 + `[R] 다시` . 페이드 인 0.6s.

**성공 기준**: 두 엔딩 모두 도달 가능. 재시작 시 새 시드 적용, 이전 상태 잔존 0.

```ts
  inventory: readonly (ItemId|null)[]   // [null,null,null]

  flags: ReadonlySet<FlagId>            // ∅
```

## 9. P0 이후 — 즉시 이어지는 것

P0가 끝나면 P1의 첫 작업은 **효자손 체인**이다 (GDD §5.4 — 프로젝트의 얼굴). P0의 구조는 그걸 받을 수 있게 설계되어 있다:

- `interaction` 시스템 자리 — F-05 게이트 태그가 **동일 인터페이스의 첫 사용자**다
- `cardBalance` — 동전이 흘러들어올 통로가 이미 뚫려 있다
- `endings[]` 배열 — 12종이 추가될 자리
- `gp_character_rigged.glb` — 할아버지가 애니 6종(`GP_SitIdle`~`GP_Recover`)과 함께 이미 대기 중
